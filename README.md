# 💊 ClickPharma

Bem-vindo ao **ClickPharma**, um projeto fictício desenvolvido como parte do aprendizado em React + TypeScript.  
O objetivo é simular uma farmácia online, com funcionalidades de **CRUD de categorias** e páginas institucionais.

- Repositório do backend: [ClickPharma-Backend](https://github.com/MaeliPalharini/projeto_final_bloco_02)

---

## 🚀 Tecnologias utilizadas

- ⚛️ [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- 🎨 [Tailwind CSS](https://tailwindcss.com/)
- 🔄 [Axios](https://axios-http.com/) para consumo da API
- 🛠️ Vite como bundler

---

## 📂 Estrutura do projeto
    src/
    ├─ assets/ # imagens e ícones
    ├─ components/ # componentes reutilizáveis (Navbar, Footer, etc.)
    ├─ models/ # interfaces TypeScript
    ├─ pages/ # páginas da aplicação (Home, Categorias, Sobre, Contato)
    ├─ services/ # integração com o backend via Axios
    ├─ App.tsx # rotas principais
    └─ index.css # estilos globais
---

## ⚙️ Funcionalidades

✅ Listar categorias (GET)  
✅ Buscar categoria por nome (GET)
✅ Criar nova categoria (POST)  
✅ Editar categoria existente (PUT)  
✅ Deletar categoria (DELETE)  
✅ Página inicial (Home)  
✅ Página "Sobre nós"  
✅ Página "Contato"  
✅ Navegação responsiva com **React Router**
